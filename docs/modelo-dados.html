2.1 Modelo de Dados

Sistema Freela Facil - Plataforma simples de freelancers

Diagrama ER

Entidades do Banco

clientes freelancers projetos propostas contratos pagamentos

O modelo possui 6 entidades, atendendo ao requisito minimo de 5 entidades.

Explicacao das Entidades

  • clientes armazena quem publica projetos na plataforma.
  • freelancers armazena os profissionais que podem enviar propostas.
  • projetos representa as demandas cadastradas pelos clientes.
  • propostas registra as ofertas feitas pelos freelancers para cada projeto.
  • contratos guarda a proposta aceita e o valor combinado.
  • pagamentos registra os valores pagos dentro de cada contrato.

Relacionamentos

Um cliente pode cadastrar varios projetos, mas cada projeto pertence a apenas um cliente.

Um projeto pode receber varias propostas. Cada proposta pertence a um projeto e a um freelancer.

Quando uma proposta e aceita, ela gera um contrato. Depois disso, o contrato pode receber varios pagamentos.
