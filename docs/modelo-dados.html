2.1 Modelo de Dados

Sistema Freela Facil - Plataforma simples de freelancers

Modelo Conceitual (MER - notação Chen)

Modelo Lógico Relacional

Entidades do Banco

clientes freelancers projetos propostas contratos pagamentos

O modelo possui 6 entidades, atendendo ao requisito minimo de 5 entidades.

Explicacao das Entidades

  • clientes armazena quem publica projetos na plataforma.
  • freelancers armazena os profissionais que podem enviar propostas.
  • projetos representa as demandas cadastradas pelos clientes.
  • propostas registra as ofertas feitas pelos freelancers para cada projeto.
  • contratos guarda a proposta aceita e o valor combinado.
  • pagamentos registra os valores pagos dentro de cada contrato.

Relacionamentos

Um cliente pode cadastrar varios projetos, mas cada projeto pertence a apenas um cliente.

Um projeto pode receber varias propostas. Cada proposta pertence a um projeto e a um freelancer.

Quando uma proposta e aceita, ela gera um contrato. Depois disso, o contrato pode receber varios pagamentos.

Mapeamento Conceitual → Lógico

Como cada elemento do MER (notação Chen) virou tabela, chave ou restrição no modelo relacional.

Conceitual (Chen)CardinalidadeLógico (relacional)
Entidades CLIENTE, FREELANCER, PROJETO, CONTRATO, PAGAMENTO-Uma tabela para cada entidade, com id SERIAL como PK
CLIENTE publica PROJETO1:Nprojetos.cliente_id → clientes(id), NOT NULL (FK no lado N)
PROJETO recebe PROPOSTA1:Npropostas.projeto_id → projetos(id), NOT NULL
FREELANCER envia PROPOSTA1:Npropostas.freelancer_id → freelancers(id), NOT NULL
FREELANCER × PROJETO (via entidade associativa PROPOSTA)N:NTabela associativa propostas com as duas FKs e atributos próprios (valor, prazo_dias, mensagem, status)
PROPOSTA gera CONTRATO1:1 (opcional)contratos.proposta_id → propostas(id) com UNIQUE, garantindo no máximo um contrato por proposta
CONTRATO possui PAGAMENTO1:Npagamentos.contrato_id → contratos(id), NOT NULL
Atributos com domínio fixo (status, valores)-Constraints CHECK (status IN (...), valor > 0, prazo_dias > 0)
